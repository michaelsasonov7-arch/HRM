# PPG Well

אפליקציית wellness (דופק, PRV, נשימה) למעקב אישי. אינה מכשיר רפואי.

## פריסה ב-GitHub Pages
1. צרו ריפו חדש והעלו אליו את כל הקבצים בתיקייה זו, בשורש הריפו (כולל `.nojekyll`).
2. Settings ← Pages ← Source: Deploy from a branch ← Branch: main, תיקייה: / (root) ← Save.
3. אחרי דקה-שתיים פתחו ב-Chrome באנדרואיד: `https://USERNAME.github.io/REPO/` ואשרו הרשאת מצלמה.
4. להתקנה על המסך הראשי: תפריט Chrome ← Add to Home screen.

הערה: לאחר עדכון קבצים יתכן שיידרש רענון כפול או סגירת האפליקציה כדי לטעון את הגרסה החדשה (המטמון מתעדכן מהרשת כשיש חיבור).
